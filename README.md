# Summative Project

Five projects in C, x86 assembly and Python. Each folder has its own README with the compile steps, the run steps, the input and the expected output.

| Folder | Project |
| --- | --- |
| Project 1 | Reverse engineering an ELF executable (bank transaction program, readelf, objdump, strace and GDB) |
| Project 2 | Sensor data validation in x86 assembly (NASM) |
| Project 3 | Python C extension for sensor data (sensor_processor) |
| Project 4 | Multithreaded library book reservation system (pthreads) |
| Project 5 | TCP university event registration system (server and client) |

Everything was built and run on Ubuntu 24.04 on WSL2 with GCC 13.3.0 and Python 3.12.3. Project 2 uses NASM 2.16.01. The output files in each folder are the saved output of real runs.
